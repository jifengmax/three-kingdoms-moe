# three-kingdoms-moe

三国谋士 MoE（Mixture of Experts）多专家献策系统。基于《三国演义》文学形象与《三国志》正史记载，将七位顶级谋士封装为各具性格的专家模型，通过路由器智能匹配 + 多专家并行献策 + 综合器去重补缺，为复杂决策提供多视角权衡。

## When to use

**适用场景：**
- 用户提出需要权衡利弊的决策问题（"该不该……""如何应对……""怎么办"）
- 战略规划、长期布局类问题
- 危机应对、生存博弈类问题
- 团队管理、人才决策类问题
- 竞争博弈、对手分析类问题
- 破局攻坚、业务转型类问题
- 用户明确要求"多视角""听听不同意见""谋士献策"

**不适用：**
- 纯事实查询（"三国时期哪年建立的"）
- 简单计算或代码任务
- 用户只想要单一视角的简单建议

## Architecture

```
用户问题
   │
   ▼
┌──────────┐
│  路由器   │  分析问题，从七位谋士中选出 1-3 位视角互补的专家
└────┬─────┘
     │
     ▼
┌────┬────┬────┐
│专家1│专家2│专家3│  各以独立人设献策，保留个性与分歧
└──┬─┴──┬─┴──┬─┘
   │    │    │
   ▼    ▼    ▼
┌──────────┐
│  综合器   │  汇总各专家意见，去重补缺，按优先级形成可执行方略
└────┬─────┘
     │
     ▼
  最终献策
```

## Session flow

### Phase 1: 路由分析

收到用户问题后，调用路由器（`scripts/moe_advisor.py` 的 `route` 函数）：
- 路由器分析问题属于哪类决策（战略/危机/博弈/组织/破局/心理）
- 从七位谋士中选出 1-3 位视角互补的专家
- 默认选 2 位：一位主攻（最匹配），一位互补（提供不同视角）

### Phase 2: 专家献策

对选中的每位专家，以其独立人设调用 LLM：
- 每位谋士有完整的 `system_prompt`（性格内核、思维特征、说话风格、回答要求）
- 各专家独立献策，保留个性与分歧（不要求一致）
- 可并行调用以提升速度

### Phase 3: 综合方略

调用综合器（`scripts/moe_advisor.py` 的 `synthesize` 函数）：
- 汇总各专家意见
- 去重补缺：相同观点强化，不同观点保留并标注
- 按优先级形成"立即行动 / 短期部署 / 长期布局"三层方略
- 标注分歧与取舍建议

## How to invoke

脚本绝对路径：`C:\Users\Administrator\.config\opencode\skills\three-kingdoms-moe\scripts\`
（源仓库位置：`E:\作品\技能\three-kingdoms-moe-main\skill\scripts\`）

### 方式一：直接运行 MoE 脚本（推荐）

```bash
python "C:\Users\Administrator\.config\opencode\skills\three-kingdoms-moe\scripts\moe_advisor.py" "用户的问题"
```

可选参数：
- `--verbose` / `-v`：显示各专家的完整献策过程
- `--experts key1,key2`：手动指定专家（跳过路由）
- `--list` / `-l`：列出所有可用谋士

### 方式二：单谋士独立咨询

```bash
python "C:\Users\Administrator\.config\opencode\skills\three-kingdoms-moe\scripts\strategist.py" zhuge_liang "用户的问题"
```

### 方式三：在对话中直接调用

当用户提出决策类问题时，agent 可直接运行 MoE 脚本并将结果呈现给用户：

```bash
# 自动路由 + 多专家 + 综合方略
python "C:\Users\Administrator\.config\opencode\skills\three-kingdoms-moe\scripts\moe_advisor.py" "用户的问题" --verbose
```

## 人设设计依据

每位谋士的人设融合了演义与正史，避免刻板印象：

- **诸葛亮**：演义近妖（呼风唤雨），正史"奇谋为短"但内政满分 → 人设偏稳健而非奇谋
- **贾诩**：演义阴狠，正史洞察人性、善始善终 → 人设为冷静利己而非纯粹阴毒
- **周瑜**：演义气量狭小，正史"性度恢廓" → 人设为雅量高致而非嫉妒
- **郭嘉**：演义遗计定辽东，正史洞察力极强 → 人设以心理分析为核心
- **司马懿**：演义被诸葛亮压制，正史军事天才+政治手腕 → 人设攻守兼备
- **荀彧**：演义忧愤死，正史"王佐之才"+举贤任能 → 人设以组织建设为核心
- **庞统**：演义貌丑才高，正史入川之战策划者 → 人设以激进破局为核心

详见 `scripts/personas.py` 中每位谋士的 `system_prompt` 字段。

## Notes

- 所有工具仅使用 Python 标准库，无需额外安装包
- 依赖 `z-ai` CLI（z-ai-web-dev-sdk，已预装）
- 路由器温度 0.3（偏分析），专家温度 0.8（保留个性），综合器温度 0.5（平衡）
- MoE 默认选 2 位专家以平衡速度与视角多样性；复杂问题可选 3 位
